휴대폰과 동기화 설정

내 GitHub 계정의 비공개 Gist 하나에 오늘 일정을 저장해서 컴퓨터·휴대폰이 같은 데이터를 보게 합니다. 최초 1회만 설정하면 됩니다.
1) 컴퓨터에서: GitHub 토큰 발급 페이지에서 gist 권한만 체크하고 토큰을 발급 → 아래에 붙여넣고 "저장소 만들기" 클릭
2) 아래 나오는 동기화 코드를 QR로 찍거나 복사해서 휴대폰에서 붙여넣기 → 적용
