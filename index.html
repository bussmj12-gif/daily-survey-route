휴대폰과 동기화 설정

내 GitHub 계정의 비공개 Gist 하나에 오늘 일정을 저장해서 컴퓨터·휴대폰이 같은 데이터를 보게 합니다. 최초 1회만 설정하면 됩니다.
1) 컴퓨터에서: GitHub 토큰 발급 페이지에서 gist 권한만 체크하고 토큰을 발급 → 아래에 붙여넣고 "저장소 만들기" 클릭
2) 아래 나오는 동기화 코드를 QR로 찍거나 복사해서 휴대폰에서 붙여넣기 → 적용

휴대폰 카메라로 QR을 찍어 코드를 복사한 뒤, 아래 붙여넣기 칸에 넣어주세요.
🚗 동선 최적화 · 🗺️ 지도

출발지·도착지와 각 검사장소 주소를 좌표로 변환해 가까운 순서로 방문 지점을 재정렬하고, 지도에 위치를 표시합니다. 직선거리 기준 계산이라 실제 도로 상황과는 다소 차이가 있을 수 있습니다.
같은 카카오 디벨로퍼스 앱의 REST API 키(주소 변환용)와 JavaScript 키(지도 표시용) 둘 다 입력해 주세요 (이 기기에만 저장됩니다). JavaScript 키를 비워두면 동선 정렬만 되고 지도는 표시되지 않습니다. REST API 키를 입력해두면 아래 검사장소 카드의 길찾기 버튼도 정확한 좌표로 카카오맵 경로 안내를 엽니다 (비워두면 카카오맵 검색으로 대체됩니다).

⏱ 시간 배분

시간

방문지(동선)를 추가하지 않아도 시간 배분에만 단독으로 추가할 수 있어요. 운항선 검사나 보유 중인 Type Approval / Works Approval처럼 특정 방문지가 없는 업무에 사용하세요. 지우기 전까지 매일 목록에 계속 남아있습니다.

"하루 근무시간"은 진행 중인 항목들의 시간 합계를 자동으로 보여주는 값이라 직접 수정할 수 없어요. 항목을 취소하거나 개별 시간을 고치면(－/＋ 버튼 또는 직접 입력) 그만큼 이 합계도 함께 줄거나 늘어요 (다른 항목엔 영향 없음). 검사비는 자동 배분 없이 직접 입력한 값만 반영됩니다.

검사장소를 누르면 카카오맵 검색이 열립니다 (앱 설치 시 자동 연결) · 길찾기 버튼은 좌표 기반으로 카카오맵 경로 안내를 바로 엽니다 (REST API 키 필요, 출발지는 카카오맵 앱이 현재 위치로 자동 설정) · 주소 복사 버튼으로 다른 앱에 붙여넣을 수 있습니다 · 전화번호를 누르면 바로 통화가 걸립니다.
동기화 데이터는 내 GitHub 비공개 Gist에만 저장되며, 발급한 토큰은 이 브라우저에만 보관됩니다.
